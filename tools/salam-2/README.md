# Salam, step 2: a form

The second step of the Salam example, which grows one tool through every part of toolbench. The tool gains two inputs, a select for the
greeting and a toggle for **يا**, and a second result kind, `error`, for a name it cannot greet.

An error names the input at fault, so the form marks that field invalid and attaches the message to it. A name in
Latin letters is refused with the position of the first one, because the later steps count Arabic letters and
cannot count an A.

# Salam, step 5: a chart

The fifth step of the Salam example, which grows one tool through every part of toolbench. It adds each letter's **abjad value**: the old order
of the Arabic alphabet, **أبجد هوز حطي كلمن سعفص قرشت ثخذ ضظغ**, in which every letter is also a number, from
ا = 1 to غ = 1000. The values are added up in the counts, listed in the table, and drawn as a bar per letter.

Conventions differ for a few letters. Here a hamza seat counts as the letter carrying it (أ as ا, ؤ as و, ئ as ي),
a hamza on its own as 1, and ta marbuta as ه, 5. With those rules أحمد is 53 and محمد is 92.

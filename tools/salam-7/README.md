# Salam, step 7: styled by the page

The last step of the Salam example, which grows one tool through every part of toolbench. The code is step 6's with two names added: the
greeting is `role: "answer"` and the counts are `role: "metrics"`. The runtime gives a role no meaning. It renders
it as `data-role`, and the page embedding the tool decides how an answer and a set of metrics look, so the same
tool is drawn large on one site and plainly on another.

Everything else, the letters, the abjad values and the count of arrangements, is explained in the earlier steps'
help.
